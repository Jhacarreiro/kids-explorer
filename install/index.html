Install Kids Explorer

A Rabbit R1 Creation where a child asks questions by voice or with a photo and hears short answers in European Portuguese.

What you need

  1. A Rabbit R1 connected to the internet.
  2. An OpenAI API key, created at platform.openai.com/api-keys in an account with credit. Answers use the GPT-5.6 Luna model and each question costs a fraction of a cent. Create a key just for this and set a spending limit on its OpenAI project.
  3. Optional: an Azure Speech key and its region, so answers are read with a voice from Portugal. The free F0 tier is enough for family use. Without it, the R1 reads the answers with its own voice.

Generate your QR code

Everything happens in this browser. This page has no internet access and sends your keys nowhere: they go only into the QR code and, once installed, onto the R1, which talks directly to OpenAI and Azure.

Scan it with the R1

  1. On the R1, open the Creations card.
  2. In the Create tab, choose Add via QR code and scan this code.
  3. Open Explorador Curioso and tap the rabbit to ask a question.

This code contains your keys. Don't share it or keep a photo of it: anyone who scans it can spend on your account. If you lose track of it, delete the key at OpenAI and generate a new one.
