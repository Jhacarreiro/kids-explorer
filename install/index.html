Instalar o Explorador Curioso

Uma Creation para o Rabbit R1 em que uma criança faz perguntas por voz ou com uma foto e ouve respostas curtas em português de Portugal.

Do que precisas

  1. Um Rabbit R1 ligado à internet.
  2. Uma chave da API da OpenAI, criada em platform.openai.com/api-keys, numa conta com saldo. As respostas usam o modelo GPT-5.6 Luna e cada pergunta custa uma fração de cêntimo. Cria uma chave só para isto e define um limite de gastos no projeto da OpenAI.
  3. Opcional: uma chave do Azure Speech e a sua região, para as respostas serem lidas com uma voz de Portugal. O plano gratuito F0 chega para uso em família. Sem ela, o R1 lê as respostas com a voz dele.

Gera o teu código QR

Tudo acontece neste browser. Esta página não tem acesso à internet e não envia as chaves para lado nenhum: ficam apenas dentro do código QR e, depois de instalado, no R1, que fala diretamente com a OpenAI e com a Azure.

Lê-o com o R1

  1. No R1, abre o cartão Creations.
  2. No separador Create, escolhe Add via QR code e lê este código.
  3. Abre Explorador Curioso e toca no coelho para fazer uma pergunta.

Este código contém as tuas chaves. Não o partilhes nem o guardes numa fotografia: quem o ler usa a tua conta. Se o perderes de vista, apaga a chave na OpenAI e gera um novo.
